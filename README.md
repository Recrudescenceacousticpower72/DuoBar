Instead of hunting through different menus or system settings, you can see and manage all three at a glance. It is designed to look like the iPhone status bar, giving your Mac a familiar and modern feel.

- Don't worry, this is normal for open-source apps.
- To open it, right-click (or Control-click) the app icon and select **Open** from the menu. Then click **Open** in the pop-up window. This is a one-time step.
